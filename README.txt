NEON DASH — GameZone mini-game
==============================

This is a complete, self-contained browser game. It works on phones and computers.
- Open neon-dash.html in a browser to play.
- Phone controls: LEFT / RIGHT buttons.
- Computer controls: arrow keys or A / D.
- Stars give bonus points; best score is saved locally on the same device/browser.

PUBLISH IT ON YOUR EXISTING GITHUB PAGES SITE (Android)
1. Extract this ZIP on your phone, or use the file manager to access neon-dash.html.
2. Open GitHub in Chrome and enter your repository: alibimohamed41-hub / gamezone-tips.
3. Open the Code tab, tap the + button, and choose Upload files (or Add file > Upload files).
4. Upload ONLY neon-dash.html. Do not replace your existing index.html.
5. Commit the changes to the main branch.
6. Wait a minute or two. Your game link will be:
   https://alibimohamed41-hub.github.io/gamezone-tips/neon-dash.html

If the link shows 404, confirm the file appears in the repository's main branch and wait a little longer.
This game is front-end only. The high score is saved in each visitor's browser and is not a shared online leaderboard.
